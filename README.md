# 1688 商品整理 Skill

根据 1688 商品链接整理商品信息，并制作颜色图片和英文尺码表，按商品分别保存到本地目录。

## 功能

- 通过浏览器读取商品标题、单价、颜色和尺码，以及颜色对应的原图和详情尺码表。
- 为每种颜色制作 1700 × 1700 像素、72 PPI、RGB 8 位、纯白背景的 PNG 主图：人物居中，上边裁切至鼻子与眼睛之间，保留身材比例、动作和服装细节。生成后进行尺寸及元数据处理和校验，并提供原尺寸 PNG 文件。
- 按原始数据制作纯白背景、全英文、英寸单位的 1:1 尺码表；缺失或矛盾的数据会注明，不自行编造。
- 按商品标题创建子目录，保存商品信息和处理后的图片。

## 使用

将本仓库作为 `1688-product-catalog` 技能目录放入支持 `SKILL.md` 的工具的技能目录，例如 Codex 的 `~/.codex/skills/1688-product-catalog`。然后提供 1688 商品链接，并要求按 1688 商品整理流程处理；也可以显式调用 `$1688-product-catalog`。

技能默认优先使用 [web-access](https://github.com/eze-is/web-access) 访问浏览器，需自行安装和配置，并根据需要登录 1688。不可用时会说明并使用其他可用浏览器。图片处理需要可用的图片编辑或生成工具。

默认输出位置为 `D:\codebuddy\库存管理\1688图片`，可按自己的电脑和需求修改 `SKILL.md` 或在任务中指定其他位置。文中的 web-access 本地路径同样需要按实际安装位置调整。

## 输出示例

```text
1688图片/
└── 商品标题/
    ├── 商品信息.txt
    ├── 黑色.png
    ├── 酒红色.png
    └── 英文尺码表.png
```

实际颜色和尺码由商品页面决定。图片经过处理后，上架前应对照原图检查服装颜色、款式和细节；尺码表应对照原始数据核对。
